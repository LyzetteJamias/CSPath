CSPath is a Java-based system that helps Computer Science students discover suitable internship opportunities and evaluate their compatibility with a specific internship position through skill-based matching, compatibility scoring, skill gap analysis, and personalized learning roadmaps. 

This system is created to support Sustainable Development Goal 4: Quality Education
