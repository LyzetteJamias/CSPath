<h1 align="center"> CSPath: Computer Science Internship Matching and Skill Development System</h1>

## Project Description

CSPath is a Java console application that helps Computer Science students find internships that fits their skills and qualifications. The system compares a student's profile against available internship positions, calculates a compatibility score, identifies matched and missing skills and recommends a persnalized learning map using resources from roadmap.sh

The internship has two modes:

**1**) Internship Discovery - For students who do do not yet know what position they want. The system analyzes the student's profile and recommends the top internships and are separated into eligible and ineligible results.

**2**) Internship Matching - For students who already have specific internship in mind. The student selects a position by ID and the system compares the student's profile against that position's requirements.

In both modes, the student can view a Personalized Learning Map containing a career roadmap and skill roadmaps for each missing skill.

## Problem being Addressed

Many Computer Science students struggle to find even one internship that matches their current technical skills, qualifications and interests. They also find it hard to tell which skills they lack for the internships they want which leads to an unclear career direction.

## Project Objectives

- Match students with suitable internships based on skills, year level, and available duration.
- Compute a compatibility score for each internship.
- Identify the skills a student already has and the skills they are missing.
- Check whether a student meets an internship's miinimum requirements.
- Recommend a learniing map, career and skill roadmpas, to close skill gaps.
- Apply Object-Oriented Programming principles in a well-structured Java system.
- Support SDG 4: Quality Education by guiding students toward the skills they need.

## Target Users

- Computer Science students looking for internships.
- Students who are unsure which internship or career path suits them.
- Students who already have atarget internship and want to know how ready they are.

## Main Features

**Student Profile Input** 
- Name, year level (1 - 4), available months, skills, and interests
- Skills and interests are entered as comma-separated values
- Duplicate and empty entires are removed automatically
- Input validation for year level and available months

**Internship Discovery Mode**
- Ranks internships by compatibility score
- Shows the top eligible scholarships
- Shows ineligible internships along with their eligibility issues
- Displays required, matched and missing skills per internship

**Internship Matching MOde**
- Lists all available internships with their IDs
- Compares the student's profile against selected internship
- Displays compatibility score, eligibility, matched skills, and missing skills

**Personalized Learning Map for Both Modes**
- Career roadmap based on the target internship
- Skills oradmaps for each missing skill
- Duplicate roadmap links are removed
- Learning resources from roadmap.sh
